How many browser tabs do I have open? **137** — counted by hand, window by window: research papers I mean to read, docs for half-finished work, a recipe, a train timetable, and the tabs I opened three weeks ago and still refuse to close.

## Run it

```sh
python3 main.py
```

It writes one number, digits only, to `/output/entry.txt` — nothing else.
